## Задания

### Задание 1 — Сортировка выбором и быстрая сортировка (2 балла)

**Файл:** `ex1.py`

Реализованы две сортировки:

- **Сортировка выбором (Selection Sort)** — сложность `O(N²)` во всех случаях.
- **Быстрая сортировка (Quick Sort)** — средняя сложность `O(N log N)`, худшая `O(N²)`.

Проведены вычислительные эксперименты на трёх типах входных данных:

1. Случайные числа
2. Отсортированный список
3. Обратно отсортированный список

Для каждого типа построен отдельный график зависимости времени выполнения от размера массива.

**Используемые библиотеки:** `time`, `random`, `matplotlib`

### Задание 2 — Числа Трибоначчи (2 балла)

**Файл:** `ex2.py`

Ряд Трибоначчи начинается с тройки `0, 0, 1`, каждое следующее число равно сумме трёх предыдущих.

Реализована рекурсивная функция `tribonacci(n)` без использования циклов.

**Базовый случай:** `n == 0` или `n == 1` → `0`; `n == 2` → `1`.  
**Рекурсивный случай:** `tribonacci(n-1) + tribonacci(n-2) + tribonacci(n-3)`.

### Задание 3 — Проверка палиндрома (вариант 1, 2 балла)

**Файл:** `ex3.py`

Дано слово из строчных латинских букв. Требуется проверить, является ли оно палиндромом, с помощью рекурсивной функции `recursive_poly(word)`. Функция возвращает строки `«YES»` или `«NO»`. Срезы с шагом, отличным от 1, не используются.

**Базовый случай:** длина слова `<= 1` → `«YES»`.  
**Рекурсивный случай:** если первый и последний символы не совпадают → `«NO»`, иначе рекурсивный вызов для слова без первого и последнего символа.

### Задание 4 — Числа Фибоначчи и Люка (2 балла)

**Файл:** `ex4.py`

Реализованы рекурсивные функции:

- `fibonacci(n)` — n-е число Фибоначчи (`F₀ = 0`, `F₁ = 1`).
- `lucas(n)` — n-е число Люка (`L₀ = 2`, `L₁ = 1`).
- `lucas_with_fib(n)` — число Люка через числа Фибоначчи: `Lₙ = Fₙ₋₁ + Fₙ₊₁`.
- `fib_with_lucas(n)` — число Фибоначчи через числа Люка: `Fₙ = (Fᵢ · Lⱼ + Fⱼ · Lᵢ) // 2`, где `i = n // 2`, `j = n - i`.

Проведено сравнение быстродействия `fibonacci()` и `fib_with_lucas()`, построен график зависимости времени выполнения от `N`.

**Используемые библиотеки:** `time`, `matplotlib`

### Задание 5 — Фрактальное дерево (2 балла)

**Файл:** `ex5.py`

Рекурсивное рисование фрактального дерева с помощью модуля `turtle`. В программу внесены следующие изменения:

1. **Толщина ветвей** уменьшается пропорционально длине: `pensize(branchLen / 10)`.
2. **Цвет ветвей** зависит от длины: короткие ветви (`< 20`) окрашены в зелёный (листья), длинные — в коричневый.
3. **Угол поворота** выбирается случайно в диапазоне от 15 до 45 градусов.
4. **Длина ветви** уменьшается на случайную величину из диапазона 5–15.

**Используемые библиотеки:** `turtle`, `random`

### Задание 6 — Кривая Коха (вариант 1, 3 балла)

**Файл:** `ex6.py`

Рекурсивное построение кривой Коха — классического фрактала. Кривая строится заменой каждого отрезка на четыре отрезка длиной в треть исходного с образованием равностороннего выступа.

**Базовый случай:** `depth == 0` — рисуется прямая линия длиной `length`.  
**Рекурсивный случай:** отрезок делится на три части, между которыми выполняются повороты на 60° влево, 120° вправо и снова 60° влево.

Глубина рекурсии — 4, начальная длина — 400 пикселей.

**Используемые библиотеки:** `turtle`

### Задание 7 — Фрактальные горы (3 балла)

**Файл:** `ex7.py`

Алгоритм рисования фрактальных гор методом средней точки. Идея: отрезок между двумя точками делится пополам, средняя точка смещается на случайную величину, после чего процесс рекурсивно повторяется для двух новых отрезков.

**Базовый случай:** `depth == 0` — рисуется прямая линия между точками.  
**Рекурсивный случай:** вычисляется середина отрезка со случайным вертикальным смещением, пропорциональным текущей глубине, и выполняются два рекурсивных вызова.

**Используемые библиотеки:** `turtle`, `random`

### Задание 8 — Мини-судоку 4x4 (3 балла)

**Файл:** `ex8.py`

Рекурсивное решение мини-судоку размером 4x4. В каждой строке, столбце и квадрате 2x2 числа от 1 до 4 встречаются ровно один раз. Пустые клетки обозначены нулями.

**Исходная матрица:**
```
0000
0020
0100
3004
```

**Базовый случай:** все клетки заполнены (нет пустых) → решение найдено.  
**Рекурсивный случай:** для первой пустой клетки перебираются числа от 1 до 4, проверяется корректность по правилам судоку, выполняется рекурсивный вызов. При неудаче — откат (backtracking).

**Правильный ответ:**
```
2341
1423
4132
3214
```

Реализованы функции:
- `print_grid(matrix)` — вывод матрицы на экран.
- `find_empty(matrix)` — поиск первой пустой клетки.
- `is_valid(matrix, num, pos)` — проверка корректности числа в позиции.
- `solve_sudoku(matrix)` — основной рекурсивный алгоритм решения.


Каждый файл запускается отдельно:

```bash

python ex3.py
python ex4.py

python ex7.py
```

## Примечания

- Во всех заданиях запрещено использование циклов там, где требуется рекурсия.
- Для замеров времени используется `time.perf_counter()`.
- В заданиях 1 и 4 размеры входных данных подобраны так, чтобы разница в производительности была наглядно видна на графике.
- Рекурсивные алгоритмы с экспоненциальной сложностью (`fibonacci`, `tribonacci`) демонстрируют быстрый рост времени выполнения при увеличении `n`.
